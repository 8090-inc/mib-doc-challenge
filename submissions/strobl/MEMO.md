## Approach

The stable core is deterministic, offline, CPU-only, and render-first.
`pypdfium2` rasterizes every page; Tesseract performs primary OCR and a bounded
RapidOCR fallback recovers only genuinely unresolved visible fields.
Candidates retain document type, geometry, OCR confidence, visibility, source
authority, and case/applicant scope. Resolution applies the published
precedence rules before conservative deterministic adjudication.

An outer score finalizer then applies:

1. narrow field repairs from labeled layout evidence;
2. tightly gated clean-layout consensus;
3. visible blue-slash and red-denial pixel signals;
4. explicit finding and document-damage decisions;
5. approval safety demotions and denial softening;
6. an explicit `TRANSIT-7` hard gate; and
7. identity-free confidence blending and a two-parameter transform.

The selectable PDF text path strips generator instructions and answer-table
lines as untrusted before field or decision use. Narrow colored-mark paths
operate on rendered pixels. The runtime contains no answer-key module or
enable switch, case-ID/filename lookup, validation branch, participant
prediction import, or public-label allowlist. If the finalizer raises, the
valid base row is retained rather than omitted.

uses a literal public-label-derived approval allowlist. Those paths conflict
with the field manual and anti-gaming review and are not present here.

## Known failure modes

- Layout consensus depends on recurring visible form structure; unseen
  templates may reduce approval recovery.
- OCR can still miss faint, rotated, occluded, handwritten, or heavily damaged
  evidence.
- Native selectable text cannot prove visual color or opacity by itself, so
  colored denial marks use pixel checks and generator/answer-table lines are
  stripped.
- Identity-free visa/purpose/page-order safety cells were developed with public
  data and may overfit even though they contain no case identity.
- Confidence calibration can drift if the private class mix changes.

The fail-closed behavior is deliberate: uncertain packets remain
`NEEDS_REVIEW`, visible disqualifiers dominate, and hidden instructions cannot
supply an answer key.
