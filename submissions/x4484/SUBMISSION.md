## Approach in brief

A staged, inspectable offline pipeline. No LLM, no VLM, no cloud OCR, no network
at runtime. The only models are a 55-feature multinomial logistic regression and
an 11-bucket reliability table, shipped as JSON totalling a few kilobytes.

```
textlayer  → visible/hidden text separation (the security boundary)
extract    → document typing, label-anchored and prose candidates
ocr        → render + tesseract, only for pages the text layer leaves unread
normalize  → closed vocabularies, OCR-confusion repair inside ID slots
resolve    → evidence precedence, cross-page conflicts, applicant attribution
policy     → deterministic rule engine from FIELD_MANUAL.md
decision   → cost-sensitive expected-payoff adjudication for weak branches
confidence → empirical reliability table, fitted out of fold
writer     → schema-safe single-writer JSONL
```

The central finding is that the PDF text layer is a trap: 21.7% of packets embed
a prompt-injection "answer key" twice per page — white-on-white and outside the
page crop — whose adjudication is always `APPROVED`, including for cases that
are truly `DENIED` with `biohazard_red`. Reading it naively buys extraction
accuracy and pays for it with the −4 catastrophic false-approval penalty. All
hidden text is filtered at a single choke point, and OCR operates on rendered
pages where such text is invisible by construction.

## Results

Organizer scorer (`scripts/evaluate.py`), 1,000 labelled training cases:

| section | score |
| --- | ---: |
| Field extraction | 41.98 / 50 |
| Classification | 65.26 / 80 |
| Confidence calibration | 15.58 / 20 |
| Missing-case penalty | −0.00 / 10 |
| **Deterministic score** | **122.87 / 150** |

The shipped models are fitted on the 801 development-fold cases only and are
regularised enough not to memorise, so the train figure carries no in-sample
inflation. On the 199-case holdout that nothing was fitted against, the honest
estimate is **~126/150**.

## Runtime

Measured under the full submission contract — `--network none`, `--read-only`,
4 vCPU, 8 GiB, `--pids-limit 512`:

| metric | value | limit |
| --- | ---: | ---: |
| Seconds per PDF | 4.99 (validation), 4.44 (train) | 6.0 |
| Validation set total | 24,927 s | 30,000 s |
| Peak container memory | ~550 MiB | 8 GiB |
| Image size | 435 MB | 4 GiB |
| Model artifacts | ~30 KB | 250 MiB each / 1 GiB total |

Predictions are reproducible: two container runs over the same input produce
byte-identical output.

## Notes

- `predictions.jsonl` was generated by the final image, unedited.
- The base image is pinned by digest; installed OCR versions are recorded at
  `/app/TOOLCHAIN.txt` inside the image.
- One policy rule was inferred from labels and cross-validated: three additional
  revoked sponsors (`SPN-9090`, `SPN-7331`, `SPN-2718`), derived in 5/5 folds.
  Rationale and supporting counts are in `MEMO.md` and `EXPERIMENTS.md`.
- Known limitations, including what is genuinely unrecoverable from visible
  evidence, are documented in `MEMO.md` rather than omitted.
