# Submission

- Public solution repository: <https://github.com/tylergibbs1/mib-doc-challenge-solution>
- Entrypoint: `docker run <image> <input_pdf_dir> <output_predictions_path>`
- Runtime: offline CPU-only Python, PyMuPDF/Poppler, Tesseract, OpenCV, and
  small scikit-learn models

The repository includes the Dockerfile, reproducible training command,
out-of-fold training report, tests, and technical documentation.
